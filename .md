`context` is the **sole** enforcement point (scope, budget, PII, audit); `app/memory` is new model+policy+composition that *calls* the context reads and never re-implements the tenant predicate; `kb` stays the single KB writer (invariant 5). KB is wrapped, not renamed.

## The memory model: four durable tiers + the frame

| Tier | Store / access | Role in the answer | Authority |
|---|---|---|---|
| Frame (working memory) | session store; **not** durable | sets the query + entity scope (an input, not a result) | n/a |
| Current state | exact structured read, validity-filtered | ground truth the reply must not contradict | highest |
| Durable knowledge | structured + semantic | policy (hard gate) + style (soft input) | policy authoritative |
| Historical episodes | semantic (`kb_embeddings`) + lexical (`content_tsv`) | graded evidence, ranked and trimmed | per proof ladder |
| Structured metrics | governed/cached projection | numeric answers with definitions | owning service |

Constraints compose deterministically (always included via floors); only the evidence tier is a ranking contest. This avoids ranking authoritative hours against a complaint on one cosine scale.

## Lifespan and schema (what drives the DB)

The five controls split **row-columns vs per-field policy**:

- **Row (per item):** `valid_from`/`valid_until` *(new)*, the four existing time clocks `source_occurred_at` (semantic age, drives freshness, non-NULL), `source_updated_at`, `materialized_at`, `curated_at`; two lifecycle axes `status` ∈ {candidate, active, retired} and `lifecycle_state` ∈ {live, tombstoned, retired, erased} coupled by the CHECK `kb_active_requires_live` (so `status='active'` alone means groundable); supersession via `source_version` + `superseded_by`; `verified_at` + `evidentiary_grade` *(new)*.
- **Policy (per field, declarative):** retention, refresh, staleness, cache-TTL, authority, sensitivity, invalidation triggers — loaded fail-closed like `registry.py`.

Key property: **validity lapse is not a write.** An expired offer stays `active`+`live` with `valid_until < now`; the current-state reader filters `valid_until >= now`, the historical reader doesn't. One row, two readers, no expiry job. An unresolved commitment has no `valid_until`, so it never time-expires — only a resolution supersedes it.

## Evidence model

Grade ladder `complaint < promise < reported < action_confirmed < verified` layered on the existing provenance axes `author_class` ∈ {merchant, customer, pie, owner} and `allowed_use` ∈ {voice_example, fact_grounding, context_only}. Grading is **fail-closed**: a deterministic floor is set from immutable provenance; a model may only *lower* it, never raise to `fact_grounding` (invariant 14). Only `action_confirmed`/`verified` certify a repair.

## Read path (assembly)

Query plan (from Context Profile) → parallel fan-out per tier → **dedup / anti-corroboration** (collapse paraphrases, exclude agent-echo by origin) → **weighted Reciprocal Rank Fusion** across arms/sources (positional, so it fuses cosine and `ts_rank_cd` without a normalization constant) → **gates vs boosts** (grade/validity as hard gates, recency/scope as soft boosts) → **budget** with ASSERT floors (`SectionFloors`: anchor/authoritative_facts/active_policy) → grade → **sufficiency** (relevance floor + typed insufficiency `no_evidence|weak|conflicting|stale|missing_required`) + an audit **receipt**. Reuses `stage2_where`, `score()` (`w_sim·sim + w_recency·decay + w_scope·tier`), and the reorder-only `Reranker` seam.

## Write path (ingest → refresh loop)

Source → `ingest` scrub-at-ingest to **per-merchant HMAC pseudonyms** (invariant 6; same person → one stable token = a privacy-preserving linkage key) → entity resolution → grade/tier → candidate event on the **spine** → single-writer KB materialization in one transaction with the dispatch barrier → **transactional-outbox** semantics with idempotent consumers → surgical refresh that advances versions, invalidates dependent drafts/summaries/embeddings, and provides bounded read-your-write. Memory never actuates (invariant 8) and makes no direct domain-system calls (invariant 13).

## Load-bearing technical decisions

- **RRF for fusion** — scale-free, no tuning, per-list weights; solves the "cosine vs `ts_rank_cd` aren't comparable" problem the code flags.
- **Valid-time primary; bitemporal scoped** — full "as-known-at X" querying confined to the Ads restatement case via an append-only audit, not general across `kb_items`.
- **Caller owns the gateway** — the query embedding is a parameter; Memory constructs no model egress (matches the existing `ctx_search`/`embed_batch` decision), keeping invariants 7/13.
- **One enforcement point** — `context` owns scope/budget/PII; the three-seam split stays safe because no reader copies the tenant predicate.

## Phasing (technical)

- **P0:** eval harness (nDCG@10, grade P/R, repair-safety assertion) + cost meters (`kb_embedding_spend` pattern) against today's path.
- **P1:** expand-contract migration (`valid_from`/`valid_until` nullable + `evidentiary_grade`) + validity predicate in `stage2_where` + deterministic grading, through the existing `review_response` profile — **no `app/memory` yet**.
- **P2–P4:** source-policy DSL (real 3rd source) → `app/memory` assembler + RRF (real 2nd agent) → metrics projection (real Ads agent), each behind an eval+cost gate.
